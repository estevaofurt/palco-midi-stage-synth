STAGE SYNTH / PALCO MIDI v1.3.0

Abra o projeto pelo site https://estevaofurt.github.io/palco-midi-stage-synth/
ou use um servidor local (python -m http.server 8000) para carregar os módulos ES.

Para funcionar, todos os arquivos JavaScript e CSS precisam estar juntos de index.html.
Para usar MIDI físico, prefira Chrome ou Edge em HTTPS/localhost e autorize o dispositivo.

O som de piano é sintetizado. As gravações originais não foram recuperadas.
SF2 PCM pode ser importado na sessão, mas SF3/SFZ não são compatíveis nesta versão.
Leia README.md e CHANGELOG.md para limites e testes.
