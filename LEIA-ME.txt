PALCO MIDI / STAGE SYNTH — V1.2.0

Versão de estabilização e melhorias do motor de síntese Web Audio.

Site: https://estevaofurt.github.io/palco-midi-stage-synth/
Código: https://github.com/estevaofurt/palco-midi-stage-synth

Para executar localmente: python -m http.server 8000 e abra http://localhost:8000.
A pasta piano/ com amostras gravadas não está incluída. O piano acústico usa síntese alternativa.
A conexão com controlador USB/MIDI físico ainda exige validação do usuário.

Testes: npm test, python tests/browser_smoke.py e python tests/browser_stress.py.
Consulte CHANGELOG.md para detalhes.
